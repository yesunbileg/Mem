# L0 архив

Энд зөвхөн бүрэн боловсруулсан эхийн ZIP хадгална. Архивын өмнө эхийг сэдэвт нь тохирсон нэртэй болгоно; агуулгын bytes өөрчлөгдөхгүй. ZIP дотор эх ба анхны/шинэ нэр, SHA-256, source/operation ID бүхий manifest.json байна. Байгаа ZIP-ийг өөрчлөхгүй. Нэг source hash-ийг давхар боловсруулахгүй. Архивыг бүхэл-store backup-д хамт нөөцөлнө; Git default-аар ZIP-ийг track хийхгүй.
